# 🎯 Solveur Simplexe en JavaScript

Ce projet est une **implémentation interactive de l’algorithme du simplexe** pour résoudre des problèmes d’optimisation linéaire (maximisation de Z). Il permet à l’utilisateur de saisir dynamiquement les données (fonction objectif et contraintes) et de visualiser les étapes de résolution.

## 🚀 Fonctionnalités

- 💡 Interface intuitive et responsive (mobile/tablette/PC)
- 📥 Saisie dynamique du nombre de variables et de contraintes
- ✍️ Entrée manuelle de la fonction objectif et des contraintes
- 🔢 Résolution automatique par méthode du simplexe (maximisation)
- 🧮 Affichage des étapes du tableau simplexe et solution optimale
- ♻️ Réinitialisation rapide de la saisie

## 🛠️ Technologies utilisées

- **HTML5**  
- **JavaScript Vanilla**  
- **[Tailwind CSS](https://tailwindcss.com/)** pour le style responsive et moderne
